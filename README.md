# Google-Microsoft-Forms-in-Ready-CSV-Format
Wenn Sie die vom Formular ausgegebene CSV-Datei importieren, werden die Fragen durch Variablennamen und die Antwortmöglichkeiten durch Zahlen ersetzt, und es werden eine CSV-Datei sowie eine Zuordnungstabelle (Codebuch) exportiert, die direkt für die Analyse verwendet werden können.


# フォーム回答整形ラボ 使い方マニュアル

GoogleフォームやMicrosoft Formsが書き出したCSVを読み込み、質問文を変数名に、選択肢を数値に置き換えて、分析用CSVと変数対応表を作るまでの手引きです。

---

## 00 はじめに

### このアプリがすること
アンケートの回答ファイルは、そのままでは分析に使えません。質問文がまるごと列名になっていたり、選択肢が「とてもそう思う」という文字のままだったり、複数選択が1つのセルに詰め込まれていたりするからです。このアプリは、その3つをまとめて整えます。

* この授業の内容は理解できましたか → `Q2`
* ややそう思う → `4`
* 演習問題, 動画教材 → `Q6_1=1` `Q6_2=1`

### 用意するもの
* Webブラウザー（Chrome、Edge、Safari、Firefox のいずれか。最近のものであれば何でも構いません）
* フォームから書き出したCSVファイル

インストールも会員登録も要りません。`フォーム回答整形ラボ.html` をダブルクリックすると、いつも使っているブラウザーで開きます。

> **SAFETY**
> 読み込んだファイルはブラウザーの中だけで処理され、外部のサーバーへは一切送信されません。インターネットにつながっていない状態でも動きます。ページを閉じるとデータは消えるので、書き出したファイルは必ず保存してください。

### 元になるCSVの用意

| フォーム | 書き出し方 |
| --- | --- |
| **Googleフォーム** | 編集画面の「回答」タブ → 右上のメニュー → **回答をダウンロード（.csv）**。スプレッドシートに連携している場合は、そのシートを「ファイル → ダウンロード → カンマ区切り形式（.csv）」で書き出しても構いません。 |
| **Microsoft Forms** | 「応答」タブ → **結果のダウンロード**。Excelブック（.xlsx）で落ちてくるので、Excelで開いて「名前を付けて保存 → CSV UTF-8」で保存し直してください。 |
| **その他** | 1行目が見出し、2行目以降が1人1行になっているCSVであれば読み込めます。区切り文字はカンマ・タブ・セミコロンのいずれでも自動判定します。 |

> **CHECK**
> ファイルの**1行目が質問文の行**になっていることを確かめてください。集計表やグラフが上に付いていたり、見出しが2行にわたっていたりすると正しく読めません。その場合はExcelで余分な行を削ってから保存し直します。

### 4つの工程
画面上部のタブが工程です。左から順に進みますが、いつでも戻れます。設定は保持されるので、02と04を行き来しながら仕上げるのが実際の使い方です。

| 工程 | すること | 省略 |
| --- | --- | --- |
| **01 CSVを読む** | ファイルを置き、読み込み結果を確かめる | 不可 |
| **02 変数を整える** | 列ごとの種類・変数名・割り当て値を確かめて直す | 可（自動判定のまま進める） |
| **03 合成得点をつくる** | 複数項目の平均点・合計点の列を追加する | 可 |
| **04 書き出す** | 出力の決まりを選び、ファイルを保存する | 不可 |

## 01 CSVを読む
最初の画面です。まずは「サンプルで試す」で一通りの流れを見てから、実際のファイルを入れることをおすすめします。

**STEP**
1. 点線の枠にCSVファイルをドラッグ＆ドロップします。「ファイルを選ぶ」からでも構いません。
2. 読み込みが終わると、回答数・列数・文字コード・書き出し元が表示されます。
3. その下の表で、読み込んだままのデータ（先頭6行）を確かめます。
4. 問題なければ「変数を整える →」へ進みます。

### 表示される4つの数字

| 項目 | 見るべきところ |
| --- | --- |
| **回答数** | フォームの回答件数と一致しているか。少なければ、空行が混じっているか見出し行がずれています。 |
| **列数** | 質問数と一致しているか。グリッド質問は項目の数だけ列になるので、質問数より多くなるのが普通です。 |
| **文字コード** | UTF-8 か Shift_JIS を自動判定した結果です。プレビューの日本語が化けていなければ問題ありません。 |
| **書き出し元** | 見出しから Googleフォーム／Microsoft Forms／一般のCSV を推定します。判定結果によって処理が変わるわけではないので、違っていても支障はありません。 |

右側には、判定できた列の種類の内訳（「評定尺度 8 / 複数選択 1 / 自由記述 2」など）が出ます。ここで極端に自由記述が多いときは、選択肢の表記ゆれで水準が増えすぎている可能性があります。

> **WHEN IT FAILS**
> 日本語が化けるときは、Excelで開いて「CSV UTF-8（コンマ区切り）」で保存し直してください。「見出し行と回答行が読み取れませんでした」と出るときは、ファイルが空か、1行しかありません。

## 02 変数を整える
このアプリの中心になる画面です。1列につき1枚のカードが並びます。**自動判定はあくまで下書き**なので、ここで確かめて直すことが、結果の正しさを決めます。

### カードの読み方
カードの左が元の質問文、矢印の右が出力される変数名です。左端の色帯が、判定された種類を表します。

* **評定尺度**: 順序のある選択肢。1〜5などの数値に置き換えます。平均を出したり相関を見たりする列です。
* **単一選択**: 順序のないカテゴリ（学部、職種など）。番号を振るか、0/1のダミー変数に展開します。
* **複数選択**: 1つのセルに複数の答えが入っている列。選択肢ごとに0/1の列へ分けます。
* **数値**: 最初から数字で答えている列。そのまま数値として書き出します。
* **自由記述**: 文章の回答。数値化せず、文字のまま書き出します。
* **記録情報**: タイムスタンプ、ID、メールアドレス、氏名など、フォームが自動で付ける列です。

カードの下段には `n=58　欠測=2　水準=5` のような数字が出ます。n は答えた人の数、欠測は空欄の数、水準は選択肢の種類数です。**水準の数が想定より多いとき**は、表記ゆれ（全角と半角、末尾の空白など）が疑われます。

### 水準チップ ── 丸の中の数字が出力される値
評定尺度と単一選択のカードには、選択肢が丸付きで並びます。丸の中の数字が、そのまま分析用CSVに書き込まれる値です。右端の小さな数字は、その選択肢を選んだ人数です。

* 丸の中をクリックすると数字を書き換えられます。0から始めたい、中央を0にして −2〜+2 にしたい、といった場合はここで直します。
* 順序が逆に判定されているときは、**「値の順を入れ替える」**を押せば一括で反転します。
* 複数選択のカードでは、青い丸が展開される列の番号です（`Q6_1`, `Q6_2` …）。こちらは値を変更できません。

### 種類を変える
変数名の下のプルダウンで種類を変えられます。変えると、その列の水準や選択肢を判定し直します。よくあるのは次の3つです。

| 状況 | 直し方 |
| --- | --- |
| 短い自由記述（「特になし」など数種類しかない）が**単一選択**と判定された | 種類を「自由記述」に変える |
| 順序があるのに**単一選択**と判定された（「週に1回／月に1回／年に1回」など） | 種類を「評定尺度」に変え、丸の中の数字を順に振り直す |
| 複数選択なのに**単一選択**と判定された（区切りが特殊、または回答が少ない） | 種類を「複数選択」に変える |

### 変数名
変数名は自動で `Q1`, `Q2`, `Q3` … と振られます。グリッド質問（「満足度 [教員の説明]」のような形）は、質問ごとに `Q5_1`, `Q5_2` … とまとまります。記録情報だけは `timestamp`、`id`、`email` のように役割の名前が付きます。
入力欄を書き換えれば好きな名前にできます。**一度書き換えた名前は、その後に種類を変えても保持されます。**分析ソフトで扱いやすいよう、スペースと記号は自動で取り除かれ、数字で始まる名前には `X` が補われます。

> **ADVICE**
> 日本語の変数名も使えますが、統計ソフトによっては文字化けや不具合の原因になります。`Q1` のような連番のままにして、意味は変数対応表（コードブック）で管理するのが安全です。

### 逆転項目
「この授業はつまらなかった」のように、他の項目と向きが逆の質問には **「逆転項目として反転する」** にチェックを入れます。丸の中の数字はそのままで、書き出すときだけ最小値と最大値を足した数から引いた値になります（1〜5なら 5,4,3,2,1）。コードブックの備考欄に「逆転処理済み」と記録されます。

### 出力から外す
各カードの「この列を出力に含める」のチェックを外すと、その列は書き出されません。**メールアドレスと氏名は、最初から外れた状態**になっています。上部のボタンでまとめて操作もできます。

* **自由記述を外す** ── 数値データだけのファイルにしたいとき
* **記録情報を外す** ── タイムスタンプやIDも要らないとき
* **すべて含める** ── 外したものを戻したいとき

列が多いときは、上部の検索欄に質問文の一部を入れて絞り込めます。種類のプルダウンで「評定尺度だけ表示」といった絞り込みもできます。

## 03 合成得点をつくる
同じものを測っている複数の項目をまとめて、1つの得点にする工程です。必要がなければ飛ばして構いません。

**STEP**
1. 変数名を入力します（例：`学習意欲`）。
2. 「計算」で平均か合計を選びます。
3. 項目のタグをクリックして選びます。選ぶと色が変わります。
4. 右側にα係数が表示されるので確かめます。
5. 「この合成得点を追加」を押します。いくつでも追加できます。

### 平均と合計
**平均**は元の項目と同じ目盛り（1〜5など）のままになるので、他の尺度と見比べやすくなります。項目数が違う尺度を並べるときも平均が便利です。**合計**は項目数を掛けた値になります。既存の尺度に「合計点で何点以上」といった基準があるときはこちらを使います。

### 欠測があるとき

| 設定 | 動き | 向いている場面 |
| --- | --- | --- |
| **答えた項目だけで計算** | 空欄の項目を除いて平均（合計）を出します。5項目中4項目に答えていれば、その4項目で計算します。 | 欠測が少なく、人数を減らしたくないとき |
| **1つでも欠測なら空欄** | 1項目でも空欄があれば、その人の合成得点は空欄になります。 | 厳密に扱いたいとき、論文で完全回答者に限定するとき |

> **NOTE**
> 「合計」と「答えた項目だけで計算」を組み合わせると、答えた項目が少ない人ほど得点が低く出てしまいます。合計を使うときは「1つでも欠測なら空欄」を選ぶか、平均に切り替えてください。

### α係数の見方
選んだ項目が同じものを測っているかの目安です（Cronbach's α）。完全回答者だけで計算した値と、その人数も併せて表示されます。

| 値 | おおよその読み |
| --- | --- |
| **.80 以上** | 十分にまとまっている |
| **.70 〜 .80** | 実用上の目安を満たす |
| **.70 未満** | 項目の向きが揃っているか（逆転処理の漏れ）、別のものを測る項目が混ざっていないかを見直す |

ただしαは項目数が多いほど高くなる性質があり、値だけで良し悪しは決まりません。低いときにまず疑うべきは、**逆転項目にチェックを入れ忘れていないか**です。02の画面に戻って確かめてください。

## 04 書き出す
出力の決まりを選ぶと、その場でプレビューが更新されます。表示されている中身が、そのままダウンロードされるファイルです。

### 設定の一覧

| 設定 | 選択肢と意味 |
| --- | --- |
| **選択肢の書き出し方** | **数値コード**＝丸の中の数字を書き出す（統計解析はこちら）。**選んだ文言のまま**＝「ややそう思う」という文字を書き出す（集計表や引用に使うとき）。 |
| **単一選択の扱い** | **1つの列に番号**＝1列に1,2,3…と入れる。**0/1のダミー変数に展開**＝選択肢ごとに列を分ける（回帰分析にそのまま投入したいとき）。 |
| **欠測の書き方** | 空欄／`NA`／`.`／`999`／`-99`。Rなら `NA` か空欄、SPSSなら `999` のような欠損値コードが扱いやすくなります。 |
| **文字コード** | **UTF-8（Excelでそのまま開ける）**＝BOM付き。ふだんはこちらで構いません。**BOMなし**＝プログラムで読むときに先頭の余分な文字を避けたい場合。 |
| **前後の空白と改行を取り除く** | 自由記述の改行がセルを壊すのを防ぎます。基本は入れたままにします。 |
| **全角の英数字を半角にそろえる** | 「１」と「1」が別の選択肢として数えられるのを防ぎます。 |
| **まったく同じ回答行を1つにまとめる** | 二重送信が疑われるときに使います。タイムスタンプを含めていると全列が一致することはまずないので、先に記録情報を外してから使ってください。 |
| **全項目が空の行を捨てる** | 送信だけして何も答えていない行を取り除きます。 |
| **最初の水準を基準にする** | ダミー展開のとき、先頭の選択肢の列を作らず基準（参照カテゴリ）にします。回帰分析で共線性を避けるための設定です。 |
| **欠測として扱う言葉** | ここに書いた言葉は空欄と同じ扱いになります。初期値は「無回答、該当なし、特になし、未回答、なし」。読点で区切って足し引きしてください。 |

> **CAUTION**
> 「なし」を欠測として扱う設定は、**「なし」が正式な選択肢である質問**（例：「アレルギーの有無」）では困ります。そういう質問があるときは、欠測として扱う言葉から「なし」を消してください。

### 上部の4つの数字
出力後の回答数・変数の数・欠測率・除いた行数が出ます。**欠測率が想定より高いとき**は、欠測として扱う言葉に本来の選択肢が入っていないか、水準の表記ゆれで一部の回答が水準に一致していないかを疑ってください。

### ダウンロード
画面下部の4つのボタンで保存します。**分析用CSVと対応表CSVは、必ずセットで保存してください。**数字だけのファイルは、対応表がないと半年後の自分にも読めません。

## 05 出力ファイルの中身

### 分析用CSV（`◯◯_analysis.csv`）
1行目が変数名、2行目以降が1人1行のデータです。そのまま R、SPSS、jamovi、HAD、Excel に読み込めます。

```csv
timestamp,Q1,Q2,Q3,Q4,Q5_1,Q5_2,Q5_3,Q6_1,Q6_2,Q6_3,Q7
2026/07/03 9:00:00,4,5,3,4,4,5,3,1,0,1,7.6
2026/07/04 10:01:00,3,4,3,3,3,4,2,0,1,0,5.2
```

### 対応表CSV（`◯◯_codebook.csv`）
どの変数がどの質問で、どの数字が何を意味するかの一覧です。論文の付録や、共同研究者への受け渡しにそのまま使えます。

| 列 | 中身 |
| --- | --- |
| **変数名** | 分析用CSVの列名 |
| **元の見出し** | フォームの質問文（そのまま） |
| **種類** | 評定尺度／単一選択／複数選択（0/1）／ダミー（0/1）／数値／自由記述／記録情報／平均得点／合計得点 |
| **値の割り当て** | `1=まったくそう思わない / 2=…` の形。逆転処理をした列は、反転**後**の値で書かれます |
| **有効回答・欠測** | その列の人数 |
| **備考** | 「逆転処理済み」「答えた項目だけで計算」など |

### Rコード（`◯◯_read.R`）
読み込みと値ラベルの付与を書いたスクリプトです。分析用CSVと同じフォルダーに置いて実行してください。

```r
dat <- read.csv("survey_analysis.csv", fileEncoding = "UTF-8-BOM", stringsAsFactors = FALSE)

# 値ラベル（必要に応じて factor に変換）
dat$Q2 <- factor(dat$Q2, levels = c(1, 2, 3, 4, 5),
                 labels = c("まったくそう思わない", "あまりそう思わない",
                            "どちらともいえない", "ややそう思う", "とてもそう思う"))

# 評定尺度をまとめて数値として扱う場合
items <- c("Q2", "Q4", "Q5_1", "Q5_2", "Q5_3")
num <- sapply(dat[items], function(x) as.numeric(as.character(x)))
summary(num)
```

> **TIP**
> 平均や相関を出したい列は factor に変換しないでください。上のコードでは、ラベルを付けたうえで、必要なときだけ `as.numeric(as.character(x))` で数値に戻す形にしています。

### 処理の記録（`◯◯_log.txt`）
読み込んだファイル名、文字コード、選んだ設定、逆転処理をした変数、作った合成得点、除いた行数などを時刻付きで書き出したテキストです。**「どう処理したか」を後から説明できるようにするためのファイル**で、研究ノートや投稿論文の手続きの記述にそのまま使えます。

## 06 自動判定のしくみ
なぜその判定になったのかが分かると、直すべきところの見当が付きます。

### 記録情報の判定
見出しが「タイムスタンプ」「メールアドレス」「ID」「開始時刻」「完了時刻」「名前」「合計点」などに一致する列を記録情報とします。このうち**メールアドレスと氏名は、最初から出力に含めません**。

### 順序の推定
選択肢の文字から、次の順に手がかりを探します。
1. **先頭の数字** ──「5：とてもそう思う」「1. まったく…」なら、その数字をそのまま値にします。「1年」「20代」のように区切り記号がなくても、全部の選択肢が異なる数字で始まっていれば使います。
2. **強さを表す言葉** ── 「まったく・全く・非常に・とても・大変・かなり」を強い（2）、「やや・少し・まあ・どちらかといえば・あまり」を弱い（0.5）とみなします。
3. **向き** ── 語尾が「〜ない／〜ません」なら負、「不満・苦手・遅い・悪い」なども負、それ以外は正とします。「どちらともいえない・普通・ちょうどよい・適切」は中央（0）に置きます。

こうして計算した点数が**全部の選択肢で異なり、かつ3水準以上**あるときに「評定尺度」とし、小さい順に 1, 2, 3 … を割り当てます。点数が同じになる選択肢があるときは順序を決められないので「単一選択」にします。

> **EXAMPLE**
> 「とても遅い／やや遅い／ちょうどよい／やや速い／とても速い」は、遅いを負・ちょうどよいを中央として 1〜5 になります。一方「東京／大阪／名古屋」のように強さの言葉がない選択肢は、すべて同点となり単一選択になります。

### 複数選択の判定
セミコロン、カンマ、読点のいずれかを探し、**回答の12%以上でその記号が使われていて**、分割してできる選択肢が25種類以下、かつ元の回答の種類数より少なくなるときに複数選択とします。Googleフォームは `, `（カンマ＋空白）、Microsoft Forms は `;` で区切るのが標準です。

> **LIMITATION**
> 選択肢の文言そのものにカンマが含まれていると、そこで分割されてしまいます。展開された選択肢のリストに不自然なものが混じっていたら、種類を「単一選択」に戻すか、元のCSVで区切り記号を別のものに置き換えてから読み込み直してください。

### 自由記述の判定
次のいずれかに当てはまる列を自由記述とします。
* 回答の種類が20を超える
* 50字を超える回答がある
* 平均32字を超え、種類が6を超える
* 見出しに「自由・感想・意見・理由・コメント・要望・記述」などが含まれ、回答がほとんど重複していない

### 数値の判定
すべての回答が数字だけ（カンマ・空白・％を除く）で、2種類以上あるときに数値とします。「5点」「3回」のように単位が付いていると数値とは判定されず、選択肢として扱われます。

## 07 分析ソフトへの取り込み

| ソフト | おすすめの設定と手順 |
| --- | --- |
| **R** | 欠測の書き方を「空欄」か `NA`、文字コードを「BOMなし」にすると素直です。付属のRコードをそのまま実行してください。`readr::read_csv()` を使うなら BOM 付きでも問題ありません。 |
| **SPSS** | 欠測の書き方を `999` にして書き出し、読み込み後に変数ビューで欠損値に `999` を指定します。値ラベルは対応表CSVの「値の割り当て」欄を見ながら入力します。 |
| **jamovi / JASP** | そのままCSVを開けます。欠測は「空欄」が扱いやすいです。読み込み後、評定尺度の列の測定水準を「順序」または「連続」に変えてください。 |
| **Excel** | 文字コードを「UTF-8（Excelでそのまま開ける）」にすれば、ダブルクリックで文字化けせずに開きます。 |
| **Python** | 「BOMなし」で書き出し、`pd.read_csv("survey_analysis.csv")` で読み込みます。欠測は空欄のままにしておくと `NaN` になります。 |

### このあとの分析
整形したCSVは、同じシリーズの各アプリにそのまま読み込めます。欠測が多いときは欠測データラボ、尺度の確認は信頼性・妥当性ラボや項目反応理論ラボ、というように使い分けてください。

## 08 困ったときは

| 症状 | 原因と対処 |
| --- | --- |
| **日本語が化ける** | 文字コードの判定が外れています。Excelで開いて「CSV UTF-8（コンマ区切り）」で保存し直してください。 |
| **「見出し行と回答行が読み取れませんでした」と出る** | ファイルが空、1行しかない、または集計行がヘッダーになっています。1行目を質問文の行にしてください。 |
| **列数が質問数より多い** | グリッド質問が項目ごとに列になっているためで、正常です。`Q5_1`, `Q5_2` のようにまとまっているか確かめてください。 |
| **同じ選択肢が2つの水準に分かれている** | 末尾の空白や全角半角の違いです。「全角の英数字を半角にそろえる」「前後の空白と改行を取り除く」の両方にチェックを入れてください。それでも残る場合は、元のCSVで表記を統一します。 |
| **順序が逆になっている** | カードの「値の順を入れ替える」を押します。1問だけなら丸の中の数字を直接書き換えても構いません。 |
| **順序のある質問が単一選択になった** | 種類を「評定尺度」に変え、丸の中の数字を順に振り直してください。 |
| **複数選択が1列のままになっている** | 区切り記号が特殊か、その記号を使った回答が全体の12%に満たないためです。種類を「複数選択」に変えてください。 |
| **自由記述が単一選択になった** | 回答の種類が少ないと起きます。種類を「自由記述」に変えてください。 |
| **欠測率が異様に高い** | 「欠測として扱う言葉」に、正式な選択肢（「なし」など）が入っていないか確かめてください。 |
| **α係数が極端に低い** | 逆転項目のチェック漏れがほとんどです。02に戻って向きの違う項目を確認してください。 |
| **ダウンロードしたファイルが見当たらない** | ブラウザーのダウンロードフォルダーに保存されています。ファイル名は元のCSV名＋`_analysis` などです。 |
| **編集した内容が消えた** | ページを再読み込みすると最初からになります。CSVを読み込み直して、書き出しまで一度で進めてください。 |
| **動作が重い** | 回答数が数千を超えると、画面の更新に時間がかかることがあります。02の画面で検索欄を使って表示を絞ると軽くなります。 |

## 09 用語の説明

| 用語 | 意味 |
| --- | --- |
| **評定尺度** | 「まったくそう思わない」〜「とてもそう思う」のように、順序のある選択肢で答えてもらう形式。リッカート尺度とも呼びます。数値に置き換えて平均や相関を計算します。 |
| **水準** | 1つの質問に用意された選択肢の種類。5件法なら水準は5です。 |
| **ダミー変数** | カテゴリを 0 と 1 の列に置き換えたもの。「教員かどうか」を1列で表します。回帰分析ではカテゴリをこの形にして投入します。 |
| **基準（参照カテゴリ）** | ダミー変数を作るとき、あえて列を作らない1つの水準。他の水準の係数は、この基準と比べた差として読みます。 |
| **逆転項目** | 尺度の中で、他の項目と向きが逆に書かれている質問。合計する前に値を反転させる必要があります。 |
| **合成得点** | 複数の項目をまとめた平均点または合計点。1つの概念を複数の質問で測ったときに作ります。 |
| **α係数** | 複数の項目がどれくらい同じものを測っているかの指標。0〜1の値をとり、.70以上がひとつの目安とされます。 |
| **欠測** | 答えられていない値。空欄のほか、「無回答」のような回答も欠測として扱えます。 |
| **コードブック** | 変数名・質問文・値の意味をまとめた対応表。データを他人（と将来の自分）が読めるようにするための書類です。 |
| **BOM** | ファイル先頭に付ける、文字コードを示す目印。付けておくとExcelがUTF-8を正しく認識します。 |

## 10 扱いの注意

### 個人情報
メールアドレスと氏名の列は最初から出力に含まれませんが、**自由記述の中に氏名や所属が書かれていることがあります**。分析用CSVを共有する前に、自由記述の中身を必ず目で確かめてください。タイムスタンプも、回答者が少ない集団では個人の特定につながることがあります。

### 処理の記録を残す
どの選択肢に何番を割り当てたか、どの項目を逆転させたか、どの回答を欠測として扱ったかは、結果を左右する判断です。「処理の記録」を書き出して、分析用CSVと同じフォルダーに保存しておいてください。研究として発表するときは、この内容をもとに手続きを記述します。

### 元のファイルは残す
このアプリは元のCSVを書き換えません。それでも、フォームから落としたままのファイルは必ず別に保管しておいてください。判定の直しに気付いたとき、そこからやり直せます。

### 自動判定を鵜呑みにしない
選択肢の順序も、複数選択の区切りも、機械が文字から推測しているにすぎません。**書き出す前に、02の画面で全部のカードに一度目を通すこと**を習慣にしてください。特に、丸の中の数字が意図した順になっているかは、結果の解釈がまるごと変わるところです。
