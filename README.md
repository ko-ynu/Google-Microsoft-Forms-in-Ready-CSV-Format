# Google-Microsoft-Forms-in-Ready-CSV-Format
Wenn Sie die vom Formular ausgegebene CSV-Datei importieren, werden die Fragen durch Variablennamen und die Antwortmöglichkeiten durch Zahlen ersetzt, und es werden eine CSV-Datei sowie eine Zuordnungstabelle (Codebuch) exportiert, die direkt für die Analyse verwendet werden können.
